# Implement hosted identity, client provisioning and durable user work

Planning key `CC-28`. Phase V2. Milestone `M5`. Type delivery.

## Outcome

The approved hosted design is implemented: an operator can provision an isolated client and case, users can authenticate with the approved permissions, and case user work persists independently of published results. Client intake has a working foundation.

## Acceptance

- [ ] Implement the client boundary, provisioning/case creation, identity provider, sessions and admin/client/publisher permissions approved in [GRS-26](https://linear.app/vaper/issue/GRS-26/resolve-client-isolation-roles-and-cloudflare-deployment) and [GRS-27](https://linear.app/vaper/issue/GRS-27/gate-the-hosted-design-before-client-intake-implementation). Product choices remain in the design decision; do not silently invent client editing rights.

- [ ] Enforce authorization server-side for case metadata, user-work reads/writes and assets. Deny unauthenticated, wrong-client, wrong-case and expired/revoked-session access.

- [ ] Implement durable user-work storage scoped by client, case and stable document identity, separately from immutable results. Define schema upgrades, concurrent-edit conflict handling and restart recovery.

- [ ] Test replacement publication and rollback against stable identities. Reused legacy refs must not move annotations to another document; ambiguous, changed or removed targets need an explicit unresolved state. Reject stale writes rather than silently losing edits.

- [ ] Implement the foundation's backup/restore primitives and exercise them with synthetic data. End-to-end recovery remains verified by [GRS-32](https://linear.app/vaper/issue/GRS-32/verify-hosted-isolation-recovery-and-release-readiness).

- [ ] Handle interrupted sign-in/session establishment with usable retry guidance (BA-19). Provide logged-out support and reviewed information-handling entry points before hosted release (BA-20); obtain approved content through the design owner.

- [ ] Transfer `src/lib/storage/cloud/**` to [GRS-28](https://linear.app/vaper/issue/GRS-28/submit-and-resume-client-document-uploads) only after this ticket is accepted; the previous owner stops writing there. The coordinator serializes later shared adapter changes.
