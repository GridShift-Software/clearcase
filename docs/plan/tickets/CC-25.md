# Gate v5, newer and JSON export compatibility

Planning snapshot, 17 October 2026. [Live issue](https://linear.app/vaper/issue/GRS-24/gate-v5-newer-and-json-export-compatibility) is the execution authority.

## Outcome

An independent reviewer establishes PASS, HOLD or FAIL at the exact integrated revision for the original v5, newer 2,131-document and JSON-style export generations through the validated results-package contract.

## Scope and dependencies

Depends on [Verify newer 2,131-document and JSON export compatibility](<https://linear.app/vaper/issue/GRS-22/import-and-verify-the-newer-2131-document-export>). Standalone Markdown authoring is explicitly after alpha and is not a prerequisite. This gate remains an input to the hosted design.

Write scope: `docs/acceptance/CC-25/**` and `tests/acceptance/CC-25/**`. Review current source and reservations before dispatch; do not duplicate already merged adapter work.

## Acceptance

* Independently re-run the original 1,689-document/42-view v5 acceptance suite without weakening its behavior.
* Verify all 2,131 newer chronology rows and account for every newer dataset. Verify the JSON-style generation against its own observed counts and source inventory; do not assume it has identical content or counts.
* Prove supported inputs produce the same versioned results-package contract with correct diagnostics, identities, original mappings and safe rendered results.
* Retain unrecognized data privately with explicit coverage/repair information. Unsupported or invalid required sections prevent publication; storing opaque residual data with a warning does not prove complete presentation. Previously published content remains available.
* Reused refs across formats or versions cannot silently attach user work to a different original. Prove document identity, anchored notes and version switching with controlled data.
* Approve the versioned manual results contract only after exact-revision evidence passes. A Markdown round-trip is not required; structured package upload and editable private preview are the alpha path.

## Verification and boundaries

Report PASS, HOLD or FAIL with commands, exit codes, exact SHA and artifacts. Independent reviewer; no missing/stale/skipped/mocked acceptance-boundary evidence counts as PASS. Source/PR approval is distinct from runtime acceptance. No new numeric performance budget is invented here; retain comparable v5 budgets and record separate baselines for different corpus sizes.

Keep original archives and production read-only. Real case material, extracted text, private screenshots and credentials stay out of Git and external services; committed fixtures are synthetic and private parity fixtures remain local. No deployment, production publication or external messages. Only the coordinator updates Linear.
