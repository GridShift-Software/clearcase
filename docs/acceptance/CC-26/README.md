## Reproduce the review

Use a clean checkout at `@INTEGRATED_SHA@`. Run `scripts/agent-tools/doctor` first. Each command below expects **exit 0** on a passing local input check; any other exit is a FAIL or HOLD with its output and artifact path recorded. Run the six evidence checks in the [proof ledger](../hosting/index.md#proof-ledger). Their original `sourceSha` values stay in the evidence files. For this docs packet, `bun run --bun check` and `bun run --bun test` expect exit 0; the planning check is `scripts/agent-tools/check-plan` with the configured Linear readback, as described in [development](../../development.md#toolchain-and-commands). A planning readback failure is not waived by this packet.

At the integrated implementation SHA, run `bun run --bun gate` and `bun run --bun gate:hosted`; both expect exit 0 and an exact-SHA `GATE PASS` summary. The hosted summary must name each real boundary or double. Its current local fixture uses identity, store, asset and audit doubles, so a local PASS cannot discharge production Clerk, remote D1/R2, email or deployment. [Hosted checks](../../development.md#hosted-checks-grs-138), [hosted verification skill](../../../.agents/skills/verify-clearcase-hosted/SKILL.md).

The user must run `.agents/skills/verify-clearcase-hosted/bin/verify-clearcase-hosted run` once at the checkpoint on the integrated revision. Expect exit 0 and a run directory with `summary.json`, `drive.json`, screenshots and a verified synthetic original download. An exit 3 is a skipped preflight, not a PASS. The user also signs off on the aggregate evidence. Only then may GRS-36 proceed beyond its already approved local bootstrap. [Skill run contract](../../../.agents/skills/verify-clearcase-hosted/SKILL.md#launch), [GRS-27 decision](../../plan/tickets/CC-26.md#user-decision--19-october-2026).

The external reviewer reviews one coherent wave PR of at most seven tickets asynchronously. Allow one written fix round and one re-request. Greptile, CI and no unresolved findings gate a wave into `dev`; the external reviewer approves only a release PR into `main`. Routine updates run at 08:30 SAST on weekdays. [Workspace review rules](../../plan/verification-and-review.md), [GRS-27 decision](../../plan/tickets/CC-26.md#user-decision--19-october-2026).
