The hosted original-delivery contract requires refusal before **any** original byte leaves, including Range and If-Range. ## Load envelope and numeric limits

The initial load model is one or two isolated clients. The synthetic v5 case has **1,689 document rows**, **1,662 originals**, **3,211,390,882 original bytes**, a **258,590,305-byte** largest original, and **37 package files totalling 6,249,551 bytes**. The 2,131-document export is a later test. The storage probe exercised 100 concurrent user-work adds, 64 MiB multipart upload parts, and an export of 385 steps with one 8 MiB part per step. These are workload and implementation measurements, not remote capacity claims. [Synthetic corpus](storage.md#the-synthetic-corpus), [storage legs](storage.md#legs), [ADR 0008 workload](../../adr/0008-workers-runtime-and-cloudflare-first-stack.md#what-the-user-confirmed-on-14-october).

The cloud proof is capped at **USD 25 per month**, with an alert at **USD 10**. Each child's numeric policy and proof envelope is recorded below. Local measurements and proposed hosted targets are identified separately; none makes a pinned cloud leg PASS.
