# Set up pstack and verification skills for agent CLI access

Planning key `CC-27`. Phase V1. Milestone `M0`. Type enablement.

## Outcome

A newly started implementation or review agent can use the project-approved pstack and verification skills through a reproducible, non-interactive CLI, with real exit codes and evidence files. This is the setup prerequisite for the local baseline; it does not implement the application.

Do not install an unrelated package merely because it is named pstack; unresolved source/access details are a HOLD.
