# Submit and resume client document uploads

Planning key `CC-16`. Phase V2. Milestone `M5`. Type delivery.

## Outcome

An authenticated client uploads files into its own case and finalizes a durable input revision.

[GRS-27](https://linear.app/vaper/issue/GRS-27/gate-the-hosted-design-before-client-intake-implementation)

## Acceptance

- [ ] Support files and folders with preserved relative paths, progress, resume and bounded retries. Reject unsafe paths and unsupported input with clear feedback.

- [ ] Finalize an immutable submission manifest with content identity and size. Handle duplicate finalization idempotently; post-finalization additions require a new revision.

- [ ] Enforce case/client authorization at every upload and asset endpoint, not only in the UI.

- [ ] Exercise interrupted upload, duplicate request, wrong-client access, storage failure and multi-gigabyte sample scale using controlled data.
