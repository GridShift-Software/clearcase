# Canonical pstack checker fixture

`check-plan.mjs` is an unchanged byte-for-byte copy of `skills/poteto-mode/scripts/check-plan.mjs` from the
installed t3-pstack plugin `2.0.0-rc.5` (registry `gitCommitSha` `bfd36b17e7ab74a7bedb2b40ae7af05a1c1284c9`,
sha256 `f4bb71a390d7a49fc7d6e7dd178d2c2c0d9575c13194dc94a7df324107b87882`). `LICENSE` is the plugin's MIT license
(`skills/poteto-mode/references/licenses/LICENSE`; original pstack (c) 2026 Lauren Tan, t3-pstack modifications
(c) 2026 Christian Bager Bach Houmann). Upstream: https://github.com/chhoumann/t3-pstack.

Why the real checker: the plugin tests prove that `verify plan-format` runs the canonical checker and reports its
own verdict. A permissive stand-in would let a broken discovery path pass. `tests/agent-tools/run.sh` verifies the
sha256 above before using the file, and it runs the same valid and invalid plan fixtures against it that the
host-dependent checker tests use. Do not edit this file; replace it with a new unchanged copy and update the hash
when a supported plugin version changes the checker.

Every other file of the synthetic plugin (SKILL.md, playbooks) is generated text from `../../make_plugin.py`.
