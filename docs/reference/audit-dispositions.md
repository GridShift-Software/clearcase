# Audit finding dispositions (BA-01 to BA-21)

The repository register for the 21 findings of the production browser audit of 8 October 2026. The dispositions are copied from the "Audit finding dispositions" table in the Linear delivery plan; this register adds the applicable v5 fixture and views, the correction or disclosure, the explicit deferral and the evidence each owner must produce. CC-23 (GRS-11) checks its coverage, CC-11 (GRS-21) verifies the V1 rows and CC-20 (GRS-32) the V2 rows.

**Status of every finding: open.** CC-01 records dispositions only and fixes nothing. A deferred source repair must not be reported as fixed, and reproducing a matching v5 defect is not evidence of correctness. A finding is closed only by its owner's evidence at an exact revision, reviewed by the gate named here.

Findings were observed in the hosted application over the newer 2,131-row export. "In the v5 fixture" says whether the same condition can be shown with the v5 baseline; where it cannot, the owner checks it against the newer export (CC-12). Production routes and source-defect IDs refer to [route-map.md](route-map.md), [defects.md](defects.md) and [view-checklist.md](view-checklist.md). Planning keys: GRS-12 = CC-03, GRS-14 = CC-04, GRS-15 = CC-05, GRS-16 = CC-06, GRS-17 = CC-07, GRS-19 = CC-09, GRS-21 = CC-11, GRS-22 = CC-12, GRS-26 = CC-15, GRS-32 = CC-20, GRS-36 = CC-28.
